# Documentation sitemap

This page is the entry point for operators, HR reviewers, payroll approvers, and developers.

## By task

### Run payroll

1. Follow [Operations](operations.md) to start the application.
2. Review calculation rules in [Payroll](payroll.md).
3. Validate and advance the run through the controlled lifecycle.
4. Confirm release controls in [Security](security.md).

### Maintain leave and payslips

1. Review source and approval behaviour in [Leave management](leave-management.md).
2. Synchronise the HR-managed leave sheet at payroll time.
3. Generate branded HTML and PDF payslips only after reconciliation.

### Understand or change the system

1. Read [Architecture](architecture.md).
2. Use the [Repository map](repository-map.md) to locate code.
3. Follow [Development](development.md) before changing schema or calculations.

## Documentation set

- [Architecture](architecture.md) — boundaries, components, and data flow.
- [Repository map](repository-map.md) — file and module sitemap.
- [Payroll](payroll.md) — pay bases, adjustments, overtime, CPF and outputs.
- [Leave management](leave-management.md) — Singapore rules and HR sheet synchronisation.
- [Operations](operations.md) — setup, launchers, validation, and recovery.
- [Security](security.md) — sensitive data, Git exclusions, and release controls.
- [Development](development.md) — environment, migrations, and verification.
